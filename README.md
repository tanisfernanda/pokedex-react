• Objetivo del proyecto: 

  Crear una página web interactiva que utilice la PokéAPI para
  consultar y mostrar información de diferentes Pokémon, permitiendo
  a los usuarios explorar de manera sencilla y organizada sus características,
  tipos, habilidades, estadísticas e imágenes mediante una interfaz amigable y dinámica.
  
• Tecnologías utilizadas.

  HTML: Para crear la estructura y organización de la página web.
  CSS: Para diseñar y personalizar la apariencia visual de la página.
  JavaScript: Para agregar interactividad y realizar las consultas a la API.
  PokéAPI: API utilizada para obtener información de los Pokémon, como nombres, imágenes, tipos, habilidades y estadísticas.
  Fetch API: Para realizar las solicitudes desde JavaScript hacia la PokéAPI y recibir los datos.
  Visual Studio Code: Editor de código utilizado para desarrollar el proyecto.
  Git/GitHub: Para el control de versiones y almacenamiento del código del proyecto.
  
• PokéAPI como API externa de consulta.

  Es una API externa que se utiliza para obtener información relacionada
  con el universo Pokémon. En el proyecto, permite realizar consultas y 
  obtener datos como nombre, imagen, tipo, habilidades, movimientos y 
  estadísticas de los Pokémon.


• JSON Server como API local de práctica.

  Es una herramienta utilizada para crear una API REST local a partir de un
  archivo JSON. En el proyecto, permite practicar el manejo de datos mediante
  operaciones como consultar, agregar, modificar y eliminar registros, simulando 
  el funcionamiento de una API real.

• Explicación de GET, POST, PATCH y DELETE.

Métodos HTTP utilizados para comunicarse con una API y realizar diferentes operaciones sobre los datos.

GET: Se utiliza para obtener o consultar información.
Ejemplo: Consultar la lista de Pokémon almacenados en JSON Server.
POST: Se utiliza para crear y agregar un nuevo registro.
Ejemplo: Registrar un nuevo Pokémon en la API local.
PATCH: Se utiliza para modificar parcialmente un registro existente, cambiando únicamente los datos necesarios.
Ejemplo: Cambiar el tipo o nombre de un Pokémon sin modificar el resto de su información.
DELETE: Se utiliza para eliminar un registro de la API.
Ejemplo: Eliminar un Pokémon almacenado en JSON Server.  

• Instrucciones: npm install, npm run dev y npm run api.
